# Modifying apollo cached data in 2 ways
- Method 1, Identify the object
cache.modify({
  id: cache.identify({
    __ref: '__typename:_id',
  }),
  fields: {
    _id(cached) {
      console.log({cached});
      return cached*something;
    },
  },
});
- Method 2, Get it by method name
cache.modify({
  fields: {
    getSocietyAccounts(cached) {
      console.log({cached});
    },
  },
});
